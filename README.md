# 🌦️ Weather App

A modern and interactive Weather Application built using **HTML, CSS, and JavaScript**.

This project allows users to check real-time weather information for different cities around the world. The application displays weather conditions like temperature, humidity, wind speed, and climate status using a clean and user-friendly interface.

---

# 🌟 Project Overview

Weather App is a frontend-based web application that provides live weather updates using weather APIs.

The main purpose of this project is to improve frontend development skills by working with:

* API Integration
* Real-Time Data Fetching
* JavaScript Async Operations
* Responsive UI Design
* DOM Manipulation
* User Interaction Handling

This project is beginner-friendly while also demonstrating advanced frontend concepts useful for interviews and portfolio building.
