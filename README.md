What is Weather App?

Weather App is a simple web application that shows weather information.

This project works inside a web browser and helps users check weather conditions easily.

Users can:

* Search any city
* See temperature
* Check weather condition
* View humidity
* See wind speed
* Get live weather updates

This project helps beginners learn frontend web development in a simple and fun way.

⸻

Why We Made This Project

People check weather every day before:

* Going outside
* Traveling
* Going to school
* Playing sports
* Planning events

But many students do not understand:

* How weather apps work
* How APIs are used
* How live data is shown
* How frontend websites become interactive

How the Project Works

1. User opens the website
2. Search bar appears
3. User enters city name
4. JavaScript sends API request
5. Weather data is received
6. Weather details appear on screen
7. User can search another city

This creates a live weather checking experience.
